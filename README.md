# Frankline Kiptoo — Portfolio Website

A responsive, dark emerald-green personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Included
- `index.html` — page structure and portfolio content
- `style.css` — design, animations, and responsive media queries
- `script.js` — mobile menu, reveal animations, project filters, and contact form
- `assets/frankline-profile.jpg` — supplied graduation portrait
- `assets/frankline-graduation.jpg` — supplied full-length graduation photo

## Run locally
1. Extract the ZIP file.
2. Open the `frankline-portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No build tools or package installation are required.

## Contact form note
The contact form validates the visitor's details and opens their default email application with a pre-filled message addressed to `bungeyykipp@gmail.com`. It does not silently send email from the website.

For direct online form submissions without requiring the visitor's email app, connect Formspree or implement a secure server-side email endpoint. Never put SMTP passwords or private API keys in frontend JavaScript.

## Personalize before publishing
1. Replace the illustrative project artwork with screenshots of your actual projects.
2. Add real GitHub repository and live demo URLs to each project card.
3. Confirm/update your LinkedIn URL.
4. Update skills to reflect your current practical experience.
5. Add certification names only after completing the relevant courses.
6. Consider adding a downloadable PDF CV.

## Publish
You can deploy this static website using GitHub Pages, Netlify, or Vercel. Upload the complete folder, keeping the `assets` directory beside the HTML, CSS, and JS files.
